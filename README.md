Приложение ToDo List. Первичный источник задач - сервер с списком, после происходит их сохранение в CoreData.
При следующем запуске источником является CoreData, а при отсутствии данных в хранилище, источником снова будет являться сервер.
В проекте присутствуют:
1) Coordinator
2) Routing
3) MVP
4) Delegate, closure
ver-1: Рабочий проект без UNIT тестов.
ver-final: Рабочий проект с добавлением UNIT тестов.
